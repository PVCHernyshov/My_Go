# My_Go

Привет. Я Паша. Это мой учебный репозиторий по Go. Изучаю язык с сентября 2026 как основной для дальнейшей работы. Начинал с языка С для школы 21 от Сбера, студентом которой и являюсь.

## Что внутри

Шесть отдельных учебных работ, каждая — свой модуль (`go.mod`).

| Папка | Тема |
|-------|------|
| `ErrorBubbling` | Проброс ошибок через цепочки функций |
| `email` | Валидация email |
| `returnError` | Возврат ошибок из функций |
| `runes` | Парсинг чисел с плавающей точкой (`parseNumber`) |
| `string` | Работа с подстроками (`substring`) |
| `ugadaj` | Игра «угадай число» |

В большинстве папок есть `main_test.go` — table-driven тесты с `t.Run`, покрывающие happy path, error path и граничные случаи.

## Стек

- Go 1.22+
- Только стандартная библиотека (внешних зависимостей нет)

## Запуск тестов

Каждая папка — отдельный модуль. Запускать тесты нужно изнутри папки:

```bash
cd runes
go test -v
